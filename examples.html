Overlays

Modal windows, toasts and off-canvas panels built on the Popover API and Invoker Commands. No JavaScript required.

Modal window

This dialog was opened with the Popover API.
This pattern is especially convenient because it adds light-dismiss behaviour: click anywhere outside the dialog to close it.

<!-- Modal window: Popover API with light-dismiss -->
<button popovertarget="my-popover-dialog">Open modal window</button>
<dialog class="modal-window" popover="manual" id="my-popover-dialog">
  <button popovertarget="my-popover-dialog" popovertargetaction="hide">Close</button>
</dialog>

<!-- Toast notification: Invoker Commands -->
<button popovertarget="my-toast">Open toast notification</button>
<div id="my-toast" popover="manual" class="toast">
  <button commandfor="my-toast" command="hide-popover">Dismiss</button>
</div>

<!-- Off-canvas panel -->
<button popovertarget="off-canvas">Open off-canvas panel</button>
<div id="off-canvas" popover class="off-canvas">…</div>

Accordion

Accordions are plain <details> elements sharing a name, so only one panel stays open at a time. Height and opacity animate with @starting-style.

Show source code 
<!-- Accordions share a name: only one panel stays open -->
<div class="accordion">
  <details name="accordion1" open>
    <summary class="heading-6">First panel<span></span></summary>
    <div class="content">
      <p>Panel content…</p>
    </div>
  </details>
  <details name="accordion1">
    <summary class="heading-6">Second panel<span></span></summary>
    <div class="content">…</div>
  </details>
</div>

<!-- The open/close animation (in your CSS) -->
<style>
details .content { opacity: 0; height: 0; overflow: hidden;
  transition: opacity .5s, height .5s, content-visibility .5s allow-discrete; }
details[open] .content { opacity: 1; height: auto;
  @starting-style { opacity: 0; height: 0; } }
</style>

<!-- Labels wrap their input: no classes needed -->
<label for="text">
  Text
  <input type="text" id="text" name="text" placeholder="Text">
  <small>Helper text with an inline hint.</small>
</label>

<label for="select">
  Select
  <select id="select" name="select" required>
    <option value="" selected>Select…</option>
    <option>Option 1</option>
  </select>
</label>

<!-- States driven by aria-invalid and disabled -->
<input type="text" aria-invalid="false" placeholder="Valid">
<input type="text" aria-invalid="true" placeholder="Invalid">
<input type="text" disabled placeholder="Disabled">

<!-- Switch: a checkbox with role="switch" -->
<label for="switch-1">
  <input type="checkbox" id="switch-1" role="switch" checked>
  Switch
</label>
