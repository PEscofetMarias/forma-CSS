Reskin forma-css without compiling a single line of Sass.

Every control on this page writes a --forma-* custom property onto :root, inline, at runtime. The stylesheet is the stock forma-css.min.css build: what changes is the token set, not the CSS. Scroll through the components and watch them all follow.

Does this work in dark mode?

Yes. Tokens declared with light-dark() pick their -dark twin automatically; if you only set the light token, dark mode falls back to it.
