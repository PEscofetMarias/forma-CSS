Reskin forma-css without compiling a single line of Sass.

Every control on this page writes a --forma-* custom property onto :root, inline, at runtime. The stylesheet is the stock forma-css.min.css build — what changes is the token set, not the CSS. Scroll through the components and watch them all follow.

Does this work in dark mode?

Yes. Every token is wrapped in light-dark(): if you only set the light one, dark mode falls back to it; the -dark twins let you diverge when you need to. The presets below set both.

Token Affects
--forma-color-primary Buttons, links, focus, checked states
--forma-border-radius-button Buttons, inputs, badges
--forma-border-radius-panel Cards, modals, dropdown menus
